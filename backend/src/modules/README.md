# Modules

后端业务模块目录。

建议模块：

- `auth`：登录、注册、邮箱验证码、刷新令牌
- `users`：用户资料、账号安全、责任书签署
- `roles`：角色与权限点
- `vulnerabilities`：漏洞提交、状态流转、审核
- `attachments`：附件上传、下载、病毒扫描占位
- `certificates`：电子证书签发、撤销、公开核验
- `announcements`：公告发布与管理
- `learning`：学习资源与靶场资源
- `points`：积分明细、积分商城、兑换记录
- `audit-logs`：审计日志
- `ai`：AI 任务、报告解析、审核辅助
