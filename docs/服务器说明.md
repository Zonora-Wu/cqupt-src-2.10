
前端单页应用路由：

```nginx

    try_files $uri $uri/ /index.html;
}
```

### 7. API 反向代理

```nginx
location /api/ {
    proxy_pass http://backend:3000;
}
```

请求转发关系：

```text
https://test.cquptsrc.asia/api/*
→ web 容器 Nginx
→ backend:3000/api/*
```

后端配置：

```text
PORT=3000
API_PREFIX=api
FRONTEND_ORIGIN=https://test.cquptsrc.asia
APP_PUBLIC_URL=https://test.cquptsrc.asia
```

### 8. Docker 网络



`web` 没有直接映射宿主机端口，说明外部访问应通过 `proxy_net` 中的上层 HTTPS 反向代理。
